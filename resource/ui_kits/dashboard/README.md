# Dashboard UI Kit

Report / dashboard layout — KPI cards, charts, lists, and structured data blocks. Used when an AI agent generates an analytical or status document (weekly report, project status, metrics dashboard).

## Files

- `index.html` — interactive demo
- `Sidebar.jsx` — left rail with navigation
- `Header.jsx` — top header with greeting + search + filters
- `KPIGrid.jsx` — the hero stat row (pastel pillow cards)
- `BarChart.jsx` — simple animated bar chart in pastel
- `RainbowProgress.jsx` — gradient progress bar
- `ActivityList.jsx` — recent activity rows with icon bubbles
- `Donut.jsx` — single-arc donut chart
