# P5 · 演化期：hand 生态，而非 hand 注册表

> **目标**：注册表从"配置"变成"基因池"。三步走，每步之间用数据说话：先**度量**（采纳率、revert 率、成本长在注册表 fabric 上），再**竞标路由**（按历史战绩分配 hand），最后**繁殖与死亡**（结晶专职 hand 的提议、低采纳 hand 的退役提议——全部以 ghost 形式等待人批准）。
> **自我一致性要求**：生态的每一次演化动作本身走幽灵管道。系统从这里开始用自己的规则治理自己。
> **验收标准**：见 §5，三步各有独立验收，且必须按序解锁（前一步的数据质量达标才允许开启下一步）。

---

## 1. 需求分析

### 1.1 三步走与解锁条件

| 阶段 | 内容 | 解锁条件 |
|---|---|---|
| E1 度量 | patch 归因统计，人看 | P0–P3 已上线；≥ 2 周真实使用数据 |
| E2 竞标 | 路由器按战绩打分选 hand | E1 指标覆盖 ≥ 80% 的 run；至少 2 个 hand 存在能力重叠域 |
| E3 繁殖与死亡 | 结晶/退役的 ghost 提议 | E2 稳定运行 ≥ 4 周；模式挖掘在离线评估中精确率 ≥ 70% |

### 1.2 功能需求

**E1 度量**

| 编号 | 需求 |
|---|---|
| FR-1 | 归因指标计算：采纳率、revert 率、编辑距离衰减、单位成本、时延（定义见 §2.1） |
| FR-2 | 指标以 block 形式长在 `sys:registry` 各 hand 条目上（P3 投影器扩展），随夜间窗口刷新 |
| FR-3 | 指标可下钻：点击采纳率 → 该 hand 最近被 revert 的 patch 列表 → 跳转现场 |

**E2 竞标**

| 编号 | 需求 |
|---|---|
| FR-4 | Router v1 替换 P1 的写死策略：`score = f(历史战绩, 领域匹配, 成本, 注意力认知†)`，†可选 |
| FR-5 | 竞标透明：命令面板显示中标 hand 及理由摘要；用户可一次性否决改派（该信号计入战绩） |
| FR-6 | speculative 模式（预算允许时）：亚军 hand 并行产出，物化为可切换的 branch/ghost 变体 |
| FR-7 | 探索保底：ε-greedy（约 10% 流量给非最优 hand），防止马太效应锁死新 hand |

**E3 繁殖与死亡**

| 编号 | 需求 |
|---|---|
| FR-8 | 模式挖掘：对 command patch 流做聚类，识别"反复出现的子任务模式" |
| FR-9 | 结晶提议：命中模式 → 生成 hand 定义草案（prompt+skills+权限+预算）→ `requires_human_seal` 的 ghost 显影在注册表 fabric |
| FR-10 | 退役提议：滚动 30 天采纳率低于阈值且无 lock 保护 → 退役 ghost（附证据链） |
| FR-11 | 新 hand 试用期：结晶后 2 周内标记 probation，只吃探索流量，期满出转正/退役报告 |

### 1.3 非功能需求

- 度量必须可复算：全部指标是操作流上的纯函数，删掉指标表可完整重建；
- 竞标决策 ≤ 50ms（打分在本地完成，不调用模型）；
- 演化动作的保守偏置：任何自动提议宁可漏报不可扰民（每 fabric 每周 ghost 提议 ≤ 3 条）。

## 2. 设计方案

### 2.1 指标定义（归因的精确语义）

以 patch 与其后继历史定义，全部可从操作流复算：

- **采纳率**：hand 的产出 patch 在 T(=72h) 窗口内未被 revert、未被人整块重写（编辑距离 > 60%）的比例；
- **revert 率**：被显式撤销（时间轴回滚或 delete）的比例——权重最重的负信号；
- **编辑距离衰减**：人对产出的小幅 refine 不算否定（≤ 30% 视为"接受并润色"，计入采纳）；
- **成本效率**：采纳 patch 的单位成本（meta.cost_usd 求和 / 采纳数）；
- **领域向量**：hand 历史上被采纳的 block_type × section 分布（竞标的匹配特征）。

驱散 ghost（P2 的 dismiss）计入该 hand 的**计划质量**子指标，与产出质量分开呈现，防止
"不敢做计划"的逆向激励。

### 2.2 Router v1（竞标器）

```
command patch ──▶ 候选集（注册表中 enabled 且权限匹配的 hand）
                    │ 打分：0.4·战绩(领域加权) + 0.25·领域匹配 + 0.2·成本 + 0.15·注意力认知
                    │ ε=0.1 探索抽样
                    ▼
              中标 hand 起 run；(若 speculative 开) 亚军并行 → 产出挂为 variant ghost
```

- 打分器是纯函数 + 可配置权重（权重进 `sys:config`，继续吃 P3 狗粮）；
- **mentions 永远短路竞标**（用户点名 = 最高指令），点名结果同样计入战绩；
- 否决改派 UI：运行徽章上"换人"入口，弹出按分数排序的候选，选择即取消当前 run 并改派，
  原中标 hand 记一次否决。

### 2.3 模式挖掘与结晶（E3 核心）

```
command 流（近 90 天）
  │ 特征化：verb + 目标 block_type + NL 文本嵌入 + 时段
  │ 聚类（HDBSCAN 或近邻图社区发现，离线夜间跑）
  ▼
候选模式（簇大小 ≥ 12 且周频 ≥ 2）
  │ 生成器 hand：起草新 hand 定义（复用簇内高采纳 run 的轨迹作为 few-shot）
  ▼
结晶 ghost 显影在 sys:registry：
  「检测到你每周约 3 次让通用 hand 做『财报摘要表格化』，
    建议结晶专职 hand_earnings_digest（预算 $0.2/次，权限只读行情）。
    [查看定义草案] [批准试用] [驱散]」
```

- 定义草案本身是一块可 refine 的子 fabric（批准前用户可以直接改它的 prompt）——
  自举范式的自然延伸；
- 退役提议同管道，证据链挂最近 10 次低质 run 的现场链接。

### 2.4 与既有机制的复用清单（本期几乎不发明新机制）

| 需要 | 复用 |
|---|---|
| 指标呈现 | P3 registry 投影器（新增 metric block 类型） |
| 提议与批准 | P2 ghost + seal |
| 试用期流量控制 | Router 的 ε 探索通道 |
| 变体并存 | P0 branch + P2 variant_of 字段 |
| 战绩审计 | P0 timeline / run 归因 |

## 3. 开发拆解

1. **M5.1** 指标计算器（离线批 + 夜间窗口刷新）+ 可复算测试（1 周）
2. **M5.2** registry 投影器扩展：metric blocks + 下钻链接（0.5 周）
3. **M5.3** Router v1：打分器 + ε 探索 + 否决改派 + mentions 短路（1 周）
4. **M5.4** speculative 变体通路（复用 branch/ghost）（0.5 周）
5. **M5.5** 模式挖掘离线管道 + 精确率评估集（1 周）
6. **M5.6** 结晶/退役 ghost 生成器 + 试用期机制（1 周）

## 4. 测试策略

- 指标可复算：随机截断操作流重放，指标一致（性质测试）；
- 竞标回放评估：用历史 command 流离线回放 Router v1 vs 写死策略，采纳率不降（守门指标）；
- 逆向激励审查（人工）：检查指标定义是否惩罚"多做计划""接手难任务"——为难任务引入
  难度归一化（按 block_type × verb 分桶比较）；
- E3 精确率：人工标注 50 个挖掘候选，precision ≥ 70% 才允许上线提议。

## 5. 验收 Demo 脚本

**E1**：打开 `sys:registry`，每个 hand 名片上活着一排指标；点击 hand_sentiment 的 72% 采纳率
→ 下钻到三条被 revert 的 patch 现场。
**E2**：对一个图表下 NL 命令 → 徽章显示"hand_market 中标（领域匹配 0.9）"；点"换人"改派
hand_target → 两者战绩当晚更新；打开 speculative，再次命令时页边出现亚军的半透明变体，一键切换采用。
**E3**：连续两周每周让通用 hand 做三次财报表格化 →（夜间挖掘后）注册表 fabric 显影出结晶提议
ghost；refine 其 prompt 草案后批准 → 新 hand 进入 probation 徽章状态；同屏另一条退役提议
指向三个月零采纳的旧 hand，批准后它优雅谢幕（历史与 wiki 归档保留）。

## 6. 风险与开放问题

| 风险 | 缓解 |
|---|---|
| 指标被玩坏（hand 只挑软柿子） | 难度归一化 + 计划质量与产出质量分列 + 人工逆向激励审查进发布清单 |
| 马太效应锁死生态 | ε 探索硬保底 + probation 通道 |
| 结晶提议扰民 | 每周 ≤ 3 条硬上限 + 簇阈值保守 + 驱散原因反哺挖掘器 |
| 退役误杀低频高价值 hand | 退役只看采纳率不看频率；lock 即豁免；退役是归档不是删除，一键复活 |

**开放问题**：
- token 预算滑块（"在这一节多花点算力"）作为 UI 原语：设计已在 ghost.budget 与 config 预算上打好锚点，
  独立小项目择机插入；
- 跨用户的战绩是否共享：涉及 P6 的社会层，明确推迟。
