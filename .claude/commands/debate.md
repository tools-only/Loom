Run a structured adversarial debate locally to produce a high-quality PRD. No server required.

**Topic:** $ARGUMENTS

---

## Your role

You are the **debate orchestrator**. You drive the debate by calling agent subagents each round. You do NOT write proposer or reviewer arguments yourself — delegate those entirely.

## Setup

Generate a debate id: `debate-<YYYYMMDD>-<4-char-slug-from-topic>`.
Create `output/debates/<id>/` directory.
Initialize `transcript = []` in memory.

## Round loop (max 14 rounds)

For each round:

**Step 1 — Host setup**
```
Agent(subagent_type="debate-host", prompt="
Round <N>. Topic: <topic>
Current layer: <layer>
Commitments so far: <commitments JSON>
Last round summary: <summary or 'none'>

Output host_setup JSON with: scope, mapping_table (if layer changed), briefing_proposer, briefing_reviewer.
")
```
Parse the JSON. Append to transcript.

**Step 2 — Proposer**
```
Agent(subagent_type="debate-proposer", prompt="
Round <N> | Layer: <scope.layer> | Focus: <scope.focus>
Briefing: <briefing_proposer>
Commitments: <commitments JSON>

Construct the affirmative position with evidence, KPIs, and citations.
")
```
Append to transcript.

**Step 3 — Reviewer**
```
Agent(subagent_type="debate-reviewer", prompt="
Round <N> | Layer: <scope.layer> | Focus: <scope.focus>
Briefing: <briefing_reviewer>
Proposer argument: <proposer output>
Commitments: <commitments JSON>

Find structural gaps, missing definitions, and alternative framings. Be adversarial.
")
```
Append to transcript.

**Step 4 — Host judgment**
```
Agent(subagent_type="debate-host", prompt="
Round <N> judgment. Topic: <topic>
Scope: <scope JSON>
Proposer: <proposer output>
Reviewer: <reviewer output>
Commitments so far: <commitments JSON>

Output host_judge JSON with: verdict (converged/continue/escalate), commitments_delta, summary.
")
```
Parse verdict. Merge commitments_delta into commitments list. Append to transcript.

**Termination:** stop when verdict is `converged` for 2 consecutive rounds AND all 4 layers (problem/ideal/gap/strategy) have at least one commitment — or when 14 rounds are reached.

## Output

After the loop:

1. Write `output/debates/<id>/transcript.json` — array of all round entries
2. Write `output/debates/<id>/spec.md` using the four-layer PRD template:

```markdown
# <topic> — PRD
**Debate ID:** <id>
**Date:** <date>
**Rounds:** <N>

## Layer 1 — Problem
<commitments with layer=problem>

## Layer 2 — Ideal State
<commitments with layer=ideal>

## Layer 3 — Gap Analysis
<commitments with layer=gap>

## Layer 4 — Strategy
<commitments with layer=strategy>

---
*Generated by local adversarial debate — <N> rounds.*
```

3. Report: "Debate complete. Spec saved to `output/debates/<id>/spec.md`."
