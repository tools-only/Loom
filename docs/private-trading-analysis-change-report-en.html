1.4 trading/policy-gate.cjs 113 lines

Policy validation for findings before write. Checks:

  1. Must bind to claim_id
  2. Must declare stance (supports / rebuts / complicates)
  3. Must include evidence or observed_at
  4. visibility must be "private"
  5. Must not contain direct buy/sell advice (regex match against buy/sell patterns)

Returns { ok: boolean, violations: string[] }. Violations produce a trading.policy_rejected event instead of writing the finding.

3. Architecture Decisions

Dependency Injection

Trading modules do not directly require('mcp/server.cjs') (which would cause circular dependencies). Instead, they receive server function references via initialize(deps). currentSession is passed as a getter to always read the live reference rather than a snapshot at require time.

Event Coexistence

Trading domain events are written through the same recordEvent() into the same events.jsonl, coexisting with existing Anchor events. Discrimination: event kind prefix — "trading.*" vs. existing "user.*" / "agent.*" / "system.*". replayTradingSession() scans all events and filters by trading_session_id.

Zero-Regression Safeguards

Guard PointMechanism
Envelope validationdomain field type is ['object', 'null']; absent or null → no extra validation
recordEvent()Function body unchanged; callers pass different kind prefix only
deliverOp()Function body unchanged; trading ops route through existing processor pool
Workspace APITrading template and session only injected when req.body.domain === 'trading.private'
Browser WS handlerTrading logic in isolated if block; else branch behavior unchanged
CSS / HTMLUses existing Bloom CSS classes only (anc-section, anc-pill, etc.); no new CSS or icon libraries
RoutesAll new routes under /trading/* prefix; no existing routes renamed or removed

4. Data Flow

Browser: user clicks data-anc="trade.intent" └→ anchor-client.js buildEnvelope() detects data-domain, adds domain field └→ WebSocket {type:"envelope", envelope:{ ..., domain:{namespace:"trading.private", action:"DECLARE_REASONING", trading_session_id:"trd_...", ...} }} └→ server.cjs wssBrowser handler ├→ validateEnvelope() — passes (domain is optional) ├→ recordEvent('user.intent', envelope) → events.jsonl ├→ tradingEvents.recordTradingEvent('trading.reasoning_declared', payload) → same events.jsonl └→ deliverOp() → processor pool → CC agent → anchor_patch → browser
